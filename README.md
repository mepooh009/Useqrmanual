# คู่มือการขอใช้บริการชุดข้อมูลผ่าน GDX

## เกี่ยวกับคู่มือนี้
คู่มือสำหรับหน่วยงานภาครัฐที่ต้องการขอใช้บริการชุดข้อมูลผ่านศูนย์แลกเปลี่ยนข้อมูลกลางภาครัฐ (Government Data Exchange: GDX)

## วัตถุประสงค์
- อธิบายขั้นตอนการค้นหาและขอใช้ชุดข้อมูล
- อธิบายการขออนุญาตจากหน่วยงานเจ้าของข้อมูล
- อธิบายการจัดเตรียมและส่งเอกสารประกอบคำขอ
- อธิบายกระบวนการขอเชื่อมโยงข้อมูลแบบ Big Lot

## ขั้นตอนการขอใช้บริการ
1. สำรวจชุดข้อมูลใน GDX Data Catalog
2. ติดต่อหน่วยงานเจ้าของข้อมูลเพื่อขออนุญาต
3. กรอกแบบฟอร์มและแนบหนังสืออนุญาต
4. ส่งเอกสารให้ DGA Contact Center
5. รอเจ้าหน้าที่ตรวจสอบและดำเนินการขึ้นทะเบียน
6. รับข้อมูลการเรียกใช้บริการทางอีเมล

## เอกสารที่เกี่ยวข้อง
- แบบฟอร์มคำขอใช้บริการหรือเชื่อมโยงข้อมูล
- หนังสืออนุญาตจากหน่วยงานเจ้าของข้อมูล
- เอกสารประกอบอื่นตามหลักเกณฑ์ที่กำหนด
